\subsection{Implementation Details}

The fine-tuning script reads the BanglaRQA training set, builds the question--passage inputs described in Chapter~3, and trains with the configuration in Table~\ref{tab:train-config}. A short test run of 150 optimizer steps compared bfloat16 with 32-bit precision before the full run: the mean loss was 14.24 in bfloat16 and 14.25 in fp32, with no overflow, and bfloat16 used less memory (14.4 GiB against 17.9 GiB) at the same speed (about 28 examples per second). The full run therefore used bfloat16.
